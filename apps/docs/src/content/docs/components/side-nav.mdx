App navigation rail for the Page `navigation` slot — sections, link/button items, optional icons, one nest level. Not the full Atlassian Navigation system.

  <Fragment slot="usage">

Items with `href` render as links; without `href` they are buttons and fire `pond-select`. Sections fire `pond-toggle` when collapsed. Nest at most one level via `slot="nested"`.
