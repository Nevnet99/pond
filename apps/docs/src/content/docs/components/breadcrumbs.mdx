Show where the user is in the hierarchy — a trail from a familiar root to the current page. Prefer the [Page header](/components/page-header/) `breadcrumbs` slot for page chrome. Leading visuals are consumer text/slots — Pond does not require an Icon system. `appearance="plain"` strips Pond visuals — you own focus paint and contrast.

<pond-breadcrumbs

```html
></pond-breadcrumbs>
```

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `PondBreadcrumbItem[]` | `[]` | Crumbs: `{ label, href?, current? }` |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** none — trail comes from `items`.

**CSS parts:** `root`, `list`, `item`, `link`, `separator`.

**Events:** none (native navigation via crumb anchors).

### Purpose

Breadcrumbs orient the user in a hierarchy and offer shortcuts up the tree. They are **not** the primary way to move between peer sections ([Side nav](/components/side-nav/), [Tabs](/components/tabs/)).

### Anatomy

1. **Nav** (`::part(root)`) — `nav` with `aria-label="Breadcrumb"`
2. **List** (`::part(list)`) — ordered list of crumbs
3. **Link / current** (`::part(link)`) — anchor when navigable; span with `aria-current="page"` when current
4. **Separator** (`::part(separator)`) — decorative `/` (`aria-hidden`)

### Content guidelines

- Start from a familiar root (Home, product name, workspace)
- Sentence case labels that match destination titles
- Do not make the current crumb a link to itself
- Keep depth readable; collapse middle segments in the product layer if trails grow long (Pond does not auto-ellipsis yet)

### Happy path vs plain

Default ships accent links, muted separators, and Pond focus rings. `appearance="plain"` keeps landmark and current semantics — **you** own color, underline, and focus paint.

**In Page header** — place the trail above the page title.

```html
<pond-page-header heading="Pond">
  <pond-breadcrumbs
    slot="breadcrumbs"
    items='[{"label":"Home","href":"/"},{"label":"Projects","href":"/projects"},{"label":"Pond","current":true}]'
  ></pond-breadcrumbs>
</pond-page-header>
```

**Prefer Side nav for peer destinations** — breadcrumbs climb ancestors; use [Side nav](/components/side-nav/) for lateral app areas.
