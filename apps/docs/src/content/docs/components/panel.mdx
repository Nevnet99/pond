Use Panel in the [Page](/components/page/) `panel` slot (or any side column) for titled contextual content — filters, inspectors, secondary actions. Keep the primary page title in [Page header](/components/page-header/) (`h1`); Panel titles are `h2`. `appearance="plain"` strips Pond visuals — you own structure and paint.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `heading` | `string` | `''` | Panel title (`h2`) when the `heading` slot is empty |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** `heading`, `actions`, `footer`, default (body).

**CSS parts:** `root`, `header`, `heading`, `actions`, `body`, `footer`.

**Events:** none.

### Purpose

Panel holds contextual side content beside the main reading column. It is **not** page chrome ([Page](/components/page/) / [Page header](/components/page-header/)) and **not** a modal ([Modal](/components/modal/)).

### Anatomy

1. **Section** (`::part(root)`) — labelled when `heading` is set
2. **Header** (`::part(header)`) — title + actions (collapses when empty)
3. **Heading** (`::part(heading)`) — `h2` from property or slot
4. **Body** (`::part(body)`) — default slot (scrolls when tall)
5. **Footer** (`::part(footer)`) — optional sticky actions region

### Content guidelines

- Sentence case panel titles (“Filters”, “Details”)
- Keep the page `h1` in Page header; Panel stays `h2`
- Footer for apply/reset clusters; don’t hide destructive confirms only in the panel without a clear label

### Happy path vs plain

Default ships header/body/footer rhythm and a footer rule. `appearance="plain"` keeps the section structure when you provide a heading — **you** own paint and any landmark labels for slotted headings.

**Filters beside a catalog** — Page header keeps the `h1`; Panel owns filter chrome.

```html
<pond-page>
  <pond-page-header slot="header" heading="Projects"></pond-page-header>
  <pond-panel slot="panel" heading="Filters">
    <!-- filter fields -->
  </pond-panel>
  <p>Results</p>
</pond-page>
```

**Prefer Drawer for temporary overlays** — if the side content should interrupt and dismiss, use [Drawer](/components/drawer/) instead of a persistent Panel.
