Use Panel in the Page `panel` slot (or any side column) for titled contextual content.

  <Fragment slot="examples">
    <PondDemo label="In Page">
      <pond-page style="min-height: 14rem; border: 1px solid var(--pond-color-border-default)">

  <Fragment slot="code">

```html
<pond-page>
  <pond-page-header slot="header" heading="Projects"></pond-page-header>
  <pond-panel slot="panel" heading="Filters">
    <pond-button slot="actions" variant="subtle">Clear</pond-button>
    <p>Filter controls</p>
    <div slot="footer">Apply</div>
  </pond-panel>
  <p>Main content</p>
</pond-page>
```

  </Fragment>

  <Fragment slot="usage">

Empty header/footer regions collapse. Prefer `heading` (renders an `h2`) or the `heading` slot — not both with conflicting titles.

    <DosDonts component="panel" />
