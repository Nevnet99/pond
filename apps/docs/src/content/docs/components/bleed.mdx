Pulls children outside a padded parent via tokenized negative margins (`all`, `inline`, `block`). Pair with [Box](/primitives/box/) surfaces. Prefer Stack/Box padding for ordinary spacing — Bleed is for flush media edges, not general layout. `appearance="plain"` strips margin chrome — you own negative space.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `all` | space scale \| `''` | `''` | Negative margin on every side |
| `inline` | space scale \| `''` | `''` | Negative margin on the inline axis |
| `block` | space scale \| `''` | `''` | Negative margin on the block axis |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips margin chrome |

**Slots:** default — content that should extend past parent padding.

**CSS parts:** `root` — bleed wrapper.

**Events:** none (presentational).

### Purpose

Bleed cancels parent padding so media or rules can sit flush. It is **not** a spacer ([Stack](/primitives/stack/) gap / [Box](/primitives/box/) padding) and **not** a flex/grid layout.

### Anatomy

1. **Host** — `pond-bleed`
2. **Wrapper** (`::part(root)`) — negative margins
3. **Content** — default slot

### Content guidelines

- Match bleed tokens to the parent’s padding step
- Prefer bleeding decorative media over interactive chrome
- Avoid nested bleeds that fight each other

### Happy path vs plain

Default applies tokenized negative margins. `appearance="plain"` unwraps — **you** own margin CSS.

**Flush hero in a card** — Image bleeds to Box edges.

```html
<pond-box padding="4" background="surface">
  <pond-bleed all="4">
    <pond-image src="/hero.png" alt="Product hero"></pond-image>
  </pond-bleed>
  <pond-stack gap="2">
    <pond-heading level="3">Card title</pond-heading>
    <pond-text>Body stays inside the padding.</pond-text>
  </pond-stack>
</pond-box>
```

**Prefer Box padding for ordinary inset** — if you are not canceling padding, do not use Bleed.
