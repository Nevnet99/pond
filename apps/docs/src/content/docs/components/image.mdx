Photographic or illustrative media with optional `src-dark` under `data-theme="dark"` and an optional caption. Prefer [Tile](/components/tile/) for compact noun markers, [Logo](/components/logo/) for brand marks, and [Object](/components/object/) for content-type glyphs. `appearance="plain"` strips Pond chrome — you own radius and caption type.

  <Fragment slot="code">

```html
<pond-image
  src="/hero-light.png"
  src-dark="/hero-dark.png"
  alt="Product hero"
  caption="Optional caption"
></pond-image>
<pond-image src="/thumb.png" alt="" appearance="plain"></pond-image>
```

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | `''` | Light (default) image URL |
| `src-dark` | `string` | `''` | Optional dark-theme URL when an ancestor has `data-theme="dark"` |
| `alt` | `string` | `''` | Alternative text; empty only when decorative |
| `caption` | `string` | `''` | Optional figcaption; wraps in `<figure>` when set |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** none — use attributes for the image.

**CSS parts:** `root` (figure when captioned), `image` (`img`), `caption` (figcaption).

**Events:** none (presentational).

### Purpose

Image shows **photos and illustrations**. It is **not** a brand mark ([Logo](/components/logo/)), noun tile ([Tile](/components/tile/)), or content-type glyph ([Object](/components/object/)).

### Anatomy

1. **Host** — `pond-image`
2. **Image** (`::part(image)`) — native `img`
3. **Caption** (`::part(caption)`) — optional figcaption
4. **Figure** (`::part(root)`) — present when `caption` is set

### Content guidelines

- Write `alt` that describes purpose, not “image of…”
- Empty `alt` only for decorative images
- Use `src-dark` when contrast or artwork must change in dark theme
- Do not make Image itself a button — wrap a real control

### Happy path vs plain

Default ships radius, caption type, and theme swap. `appearance="plain"` unwraps — **you** own chrome; `alt` rules stay.
