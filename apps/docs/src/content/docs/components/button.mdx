### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'primary' \| 'secondary' \| 'subtle' \| 'danger' \| 'link'` | `'primary'` | Emphasis / intent |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type |
| `disabled` | `boolean` | `false` | Removes from tab order; prefer validate-while-pressable |
| `pending` | `boolean` | `false` | Focusable busy state; blocks activation; shows spinner |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |
| `aria-label` | `string` | — | Name when slot text is insufficient (icon-only) |

**Slots:** default — label content.

**CSS parts:** `button` (native control), `pending` (spinner host while pending).

**Events:** standard `click` on the host when not `disabled` / `pending`.

### Purpose

Button fires an action on the current view (submit, save, delete, open a dialog). It is **not** for moving to another page — that is [Link](/components/link/).

### Anatomy

1. **Button surface** (`::part(button)`) — native `<button>`
2. **Label** — default slot
3. **Pending spinner** (`::part(pending)`) — only when `pending`

### When to use each variant

| Variant | Use when |
| --- | --- |
| `primary` | The main call to action on a view |
| `secondary` | An alternate action beside primary (Cancel, Back) |
| `subtle` | Low-emphasis chrome — toolbars, dense tables |
| `danger` | Destructive or irreversible actions |
| `link` | In-flow actions without button chrome (not page navigation) |

### Content guidelines

- Sentence case labels (“Save changes”, not “Save Changes”)
- Prefer specific verbs (“Publish page”, not “OK” / “Submit”)
- Keep labels short; truncation must still expose the full name to AT via the slot text or `aria-label`
- Match the verb on the button to the outcome (“Delete” → confirm copy says delete)

### Happy path vs plain

Default appearance ships Pond chrome and focus ring. `appearance="plain"` keeps behavior, slots, parts, and semantics — **you** own focus paint and contrast.
