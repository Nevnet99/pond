  <Fragment slot="usage">

| Variant | Use when |
| --- | --- |
| `primary` | The main call to action on a view |
| `secondary` | An alternate action beside primary (Cancel, Back) |
| `subtle` | Low-emphasis chrome — toolbars, dense tables |
| `danger` | Destructive or irreversible actions |
| `link` | In-flow actions without button chrome (not page navigation) |

**Do** use for actions the user triggers. **Don't** use for navigation between pages — use Link (when it ships). Prefer one `primary` per region.
