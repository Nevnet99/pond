Layout helper that wraps related [Tag](/components/tag/) children in a named group. Style and remove behavior come from Tag — Tag group only provides wrap layout and `role="group"`. `appearance="plain"` strips Pond gap chrome — you own spacing and contrast.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | `'Tags'` | Accessible name for `role="group"` (`aria-label`) |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** default — one or more `pond-tag` (or compatible) children.

**CSS parts:** `root` — flex wrap row with `role="group"`.

**Events:** none from the group — listen on child Tags for `pond-remove`.

### Purpose

Group related tags with wrapping layout and an accessible group name. Not a substitute for Tag itself, and not a status list ([Lozenge](/components/lozenge/)).

### Anatomy

1. **Root** (`::part(root)`) — `role="group"` + `aria-label` from `label`  
2. **Default slot** — Tag children

### Content guidelines

- `label` describes the set (“Filters”, “Topics”), not a single tag
- Keep one taxonomy per group
- Removable children still need operable, named remove controls

### Happy path vs plain

Default ships flex wrap + gap. Plain keeps group semantics — **you** own spacing chrome.

**Prefer a single Tag** when there is only one chip and no group name is needed. Prefer Lozenge for status, not Tag group.
