### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'lg'` | Display scale step |
| `muted` | `boolean` | `false` | Muted foreground (ignored when plain) |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** default — metric value (digits / short units).

**CSS parts:** `root` — metric `<p>`.

**Events:** none (presentational).

### Purpose

Metric text is for **short numbers** people compare at a glance. It is **not** body copy ([Text](/primitives/text/)) and **not** a section title ([Heading](/primitives/heading/)).

### Anatomy

1. **Host** — `pond-metric-text`
2. **Value** (`::part(root)`) — tabular display numeral
3. **Content** — default slot (the number)

### Content guidelines

- Digits and short units only (`48`, `3%`, `1.2k`) — not sentences
- Always pair with a visible label or caption naming the metric
- Sentence-case unit labels in adjacent Text

### Happy path vs plain

Default ships display face, tabular nums, weight, and size steps. `appearance="plain"` unwraps — **you** own type CSS and contrast; keep a visible label.
