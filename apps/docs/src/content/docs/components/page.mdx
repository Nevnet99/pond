Compose app chrome with slots — [Banner](/components/banner/), [Side nav](/components/side-nav/), [Page header](/components/page-header/), and a contextual [Panel](/components/panel/) sit around the main content. Empty named slots collapse so unused regions are not exposed. `appearance="plain"` strips Pond layout chrome — you own landmarks and paint.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual/layout CSS |

**Slots:** `banner`, `navigation`, `header`, `panel`, default (main).

**CSS parts:** `root`, `banner`, `body`, `navigation`, `main-column`, `header`, `content`, `panel`.

**CSS variables:** `--pond-page-nav-width` (default `15rem`), `--pond-page-panel-width` (default `18rem`).

**Events:** none.

### Purpose

Page is the app chrome shell: optional banner and side columns around a `main` reading column. It is **not** a card, dialog, or nested layout primitive — do not nest Page inside Page.

### Anatomy

1. **Banner** (`::part(banner)`) — full-width top slot
2. **Navigation** (`::part(navigation)`) — start `<aside>` when filled
3. **Header** (`::part(header)`) — top of the main column
4. **Content** (`::part(content)`) — `<main>` wrapping the default slot
5. **Panel** (`::part(panel)`) — end `<aside>` when filled

### Content guidelines

- Put the primary reading content in the default slot
- One [Page header](/components/page-header/) `h1` per page
- Keep navigation and panel for chrome / context — not the primary article

### Happy path vs plain

Default ships canvas background, column borders, and responsive stacking. `appearance="plain"` uses `display: contents` — **you** own landmarks, columns, and paint while slots still project.

**Full chrome** — Banner + Side nav + Page header + Panel around main.

```html
<pond-page>
  <pond-banner slot="banner">Maintenance window tonight</pond-banner>
  <pond-side-nav slot="navigation" label="App">...</pond-side-nav>
  <pond-page-header slot="header" heading="Projects"></pond-page-header>
  <pond-panel slot="panel" heading="Filters">...</pond-panel>
  <article>Main content</article>
</pond-page>
```

**Prefer a single Page per view** — nest layout with Flex/Grid primitives inside `main`, not another Page.
