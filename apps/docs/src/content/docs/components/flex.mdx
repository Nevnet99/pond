Flexbox with direction, wrap, align, justify, and tokenized gap. Prefer [Stack](/primitives/stack/) or [Inline](/primitives/inline/) when those cover the layout; [Grid](/components/grid/) for equal-width columns; [Box](/primitives/box/) for surface only. `appearance="plain"` strips flex chrome — you own layout CSS.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `'row' \| 'column' \| 'row-reverse' \| 'column-reverse'` | `'row'` | Flex direction |
| `wrap` | `boolean` | `false` | Allow wrapping |
| `align` | `'stretch' \| 'start' \| 'center' \| 'end' \| 'baseline'` | `'stretch'` | Cross-axis alignment |
| `justify` | `'start' \| 'center' \| 'end' \| 'between' \| 'around' \| 'evenly'` | `'start'` | Main-axis distribution |
| `gap` | space scale (`'0'`–`'12'`) | `'2'` | Gap between children |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips flex chrome |

**Slots:** default — flex children (DOM order should match reading order).

**CSS parts:** `root` — flex container.

**Events:** none (presentational).

### Purpose

Flex is the escape hatch when [Stack](/primitives/stack/) / [Inline](/primitives/inline/) are too narrow. It is **not** equal-column layout ([Grid](/components/grid/)) and **not** a surface ([Box](/primitives/box/)).

### Anatomy

1. **Host** — `pond-flex`
2. **Container** (`::part(root)`) — flexbox
3. **Children** — default slot

### Content guidelines

- Prefer Stack/Inline first; Flex when you need reverse or `evenly`
- Keep DOM order aligned with reading/tab order even if justify changes spacing
- Avoid reverse directions unless the reading order still makes sense

### Happy path vs plain

Default ships flex direction, wrap, align, justify, and gap tokens. `appearance="plain"` unwraps — **you** own flex CSS.
