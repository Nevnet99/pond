Prefer [Image](/components/image/) for photos, [Object](/components/object/) for inline content-type glyphs beside titles, and [Logo](/components/logo/) for brand marks. `appearance="plain"` strips Pond chrome — you own the square surface.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tile footprint |
| `label` | `string` | `''` | Accessible name when the slot is visual-only (`role="img"`) |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** default — short label text or nested media (icon / image).

**CSS parts:** `root` — tile surface.

**Events:** none (presentational). Wrap a control if the tile must activate.

### Purpose

Tile is a **rounded square noun** for grids and pickers. It is **not** a photo hero ([Image](/components/image/)), brand mark ([Logo](/components/logo/)), or inline type glyph ([Object](/components/object/)).

### Anatomy

1. **Host** — `pond-tile`
2. **Surface** (`::part(root)`) — bordered square
3. **Content** — default slot (text and/or icon)

### Content guidelines

- Short labels only — one or two words
- Set `label` when the slot is icon-only
- Do not treat Tile as a button without wrapping a real control

### Happy path vs plain

Default ships border, radius, surface, and size steps. `appearance="plain"` unwraps — **you** own the square; naming rules stay.
