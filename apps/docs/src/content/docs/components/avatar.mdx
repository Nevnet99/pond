Represents a person — photo, initials, then user icon. Prefer [Avatar group](/components/avatar-group/) for overlapping stacks; [Object](/components/object/) `type="person"` for a content-type cue, not identity; [Icon](/components/icon/) for non-person UI glyphs. `appearance="plain"` strips Pond chrome — you own the circle.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | `''` | Photo URL; falls back to initials, then user icon |
| `initials` | `string` | `''` | Initials fallback when `src` is empty or fails visually |
| `label` | `string` | `''` | Accessible name (`role="img"`) — required for meaningful avatars |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Face size |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** none — content comes from `src` / `initials` / icon fallback.

**CSS parts:** `root`, `image`.

**Events:** none (presentational). Wrap a control if the avatar must activate.

### Purpose

Avatar identifies a **person or entity**. It is **not** a content-type glyph ([Object](/components/object/)), brand mark ([Logo](/components/logo/)), or overlapping stack ([Avatar group](/components/avatar-group/)).

### Anatomy

1. **Host** — `pond-avatar`
2. **Face** (`::part(root)`) — circle surface
3. **Image** (`::part(image)`) — photo when `src` is set
4. **Fallback** — initials text or user icon

### Content guidelines

- Always set `label` for meaningful avatars
- Prefer two-letter initials from the display name
- In dense tables, also show a visible name — do not rely on a tiny face alone

### Happy path vs plain

Default ships circle, sizes, and fallbacks. `appearance="plain"` unwraps — **you** own the face chrome; naming rules stay.
