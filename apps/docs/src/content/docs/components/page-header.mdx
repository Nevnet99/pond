Compose breadcrumbs, title, actions, and optional bottom tabs into slots — Pond does not hard-wire those children.

```html
<pond-page-header heading="Projects">
  <pond-breadcrumbs slot="breadcrumbs" ...></pond-breadcrumbs>
  <pond-button slot="actions">New</pond-button>
  Subtitle
  <pond-tabs slot="bottom" ...></pond-tabs>
</pond-page-header>
```
