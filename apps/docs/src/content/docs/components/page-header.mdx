Compose breadcrumbs, title, actions, and optional bottom tabs into slots — Pond does not hard-wire those children. Prefer one Page header per [Page](/components/page/) (`header` slot). `appearance="plain"` strips Pond visuals — you own focus paint and contrast.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `heading` | `string` | `''` | Page title when the `title` slot is empty |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** `breadcrumbs`, `title`, `actions`, `bottom`, default (description / subtitle).

**CSS parts:** `root`, `breadcrumbs`, `main`, `text`, `title`, `description`, `actions`, `bottom`.

**Events:** none.

### Purpose

Page header is the title chrome for a view: trail, `h1`, actions, and optional bottom region. It is **not** a card header or panel title ([Panel](/components/panel/) uses `h2`).

### Anatomy

1. **Header** (`::part(root)`) — `header` landmark
2. **Breadcrumbs** (`::part(breadcrumbs)`) — optional trail slot
3. **Title** (`::part(title)`) — `h1` from `heading` or `title` slot
4. **Description** (`::part(description)`) — default slot
5. **Actions** (`::part(actions)`) — primary controls
6. **Bottom** (`::part(bottom)`) — optional Tabs / filters

### Content guidelines

- One `h1` per page — prefer `heading` or a single `title` slot child
- Sentence case titles matching the nav label when possible
- Keep actions to the primary jobs for this view; move overflow into a Menu
- Description is optional supporting copy — not a second heading

### Happy path vs plain

Default ships title scale, muted description, and action clustering. `appearance="plain"` keeps the `header` / `h1` structure — **you** own type and focus paint on slotted controls.

**Page + header + breadcrumbs** — standard product chrome.

```html
<pond-page>
  <pond-page-header slot="header" heading="Projects">
    <pond-breadcrumbs
      slot="breadcrumbs"
      items='[{"label":"Home","href":"/"},{"label":"Projects","current":true}]'
    ></pond-breadcrumbs>
    <pond-button slot="actions" variant="primary">New project</pond-button>
  </pond-page-header>
  <p>Main content</p>
</pond-page>
```

**Prefer Panel for side titles** — contextual `h2` titles belong in [Panel](/components/panel/), not a second Page header.
