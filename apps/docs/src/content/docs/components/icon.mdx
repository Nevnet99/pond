Named UI glyphs from the built-in path map, or a slotted custom SVG. Prefer [Object](/components/object/) for content-type cues, [Tile](/components/tile/) for labeled noun squares, and [Avatar](/components/avatar/) for people. Icon is not a control — wrap with [Button](/components/button/) for actions. `appearance="plain"` strips Pond size CSS — you own dimensions.

```html
<pond-icon name="check" label="Check"></pond-icon>
<pond-icon name="info"></pond-icon>
<pond-icon name="search" size="lg" label="Search"></pond-icon>
<pond-icon appearance="plain" name="check" label="Check"></pond-icon>
```

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | built-in key \| `''` | `''` | Path from `pondIconPaths`; empty → use slot |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Glyph size |
| `label` | `string` | `''` | Accessible name; empty = decorative (`aria-hidden`) |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond size CSS |

**Slots:** default — custom SVG when `name` is empty.

**CSS parts:** `icon` — SVG root.

**Events:** none (presentational).

### Purpose

Icon draws a small UI glyph. It is **not** a person ([Avatar](/components/avatar/)), content-type marker ([Object](/components/object/)), or photo ([Image](/components/image/)).

### Anatomy

1. **Host** — `pond-icon`
2. **Glyph** (`::part(icon)`) — SVG (or slotted markup)
3. **Name** — `label` when meaningful

### Content guidelines

- Label meaningful icons; omit label for decorative ones next to text
- Never ship icon-only actions without a name on the **control** (Button `aria-label`)
- Keep custom slotted SVGs with a viewBox and currentColor fill when possible

### Happy path vs plain

Default ships size steps and `currentColor` fill. `appearance="plain"` unwraps — **you** own dimensions; labelling rules stay.

**Icon-only action** — put the name on Button, keep Icon decorative.

```html
<pond-button variant="subtle" aria-label="Search">
  <pond-icon name="search"></pond-icon>
</pond-button>
```

**Prefer Object for content types** — document/folder/person glyphs beside row titles belong on [Object](/components/object/), not a generic Icon name.
