Consumer brand mark — pass your own `src` and wordmark. Pond does not ship vendor logos. Prefer [Image](/components/image/) for non-brand photography, [Tile](/components/tile/) / [Object](/components/object/) for content nouns. With `href`, Logo navigates like a link. `appearance="plain"` strips Pond chrome — you own focus paint when linked.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | `''` | Brand image URL |
| `alt` | `string` | `''` | Image (and overall) name; empty when wordmark carries the brand |
| `href` | `string` | `''` | When set, renders as a native `<a>` |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Mark + wordmark scale |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** default — wordmark / brand name text.

**CSS parts:** `root` (span or anchor), `image`, `wordmark`.

**Events:** standard navigation when `href` is set.

### Purpose

Logo is the **product brand mark**. It is **not** photography ([Image](/components/image/)), a content noun ([Tile](/components/tile/) / [Object](/components/object/)), or a person ([Avatar](/components/avatar/)).

### Anatomy

1. **Host** — `pond-logo`
2. **Root** (`::part(root)`) — `span` or `<a>` when `href` is set
3. **Image** (`::part(image)`) — optional mark
4. **Wordmark** (`::part(wordmark)`) — default slot

### Content guidelines

- Pass your own assets — Pond never ships third-party logos
- Empty `alt` when the wordmark names the brand; set `alt` for image-only marks
- Linked logos need an accessible name via wordmark or `alt`

### Happy path vs plain

Default ships size, weight, gap, and focus ring when linked. `appearance="plain"` unwraps — **you** own focus paint and color when `href` is set.
