Nested rows expand in place with indent. Prefer [Table](/components/table/) for flat grids and [Dynamic table](/components/dynamic-table/) for sort + pagination without nesting. No remote children API or drag-and-drop in this phase. `appearance="plain"` strips Pond chrome — you own borders, toggle chrome, and contrast.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `caption` | `string` | `''` | Table caption |
| `columns` | `{ key: string; label: string }[]` | `[]` | Column headers; first column hosts the toggle |
| `nodes` | `{ id: string; cells: Record<string,string>; children?: nodes[] }[]` | `[]` | Tree data |
| `expanded-ids` | `string[]` | `[]` | Expanded parent ids |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** none.

**CSS parts:** `root`, `table`, `th`, `td`, `tr`, `toggle`, `cell-start`.

**Events:** `pond-toggle` — `{ detail: { id, expanded } }`.

### Purpose

Show hierarchical rows that expand and collapse in place. Not for sort/pagination (Dynamic table) or flat read-only grids (Table).

### Anatomy

1. **Root** (`::part(root)`) — scroll container  
2. **Table** (`::part(table)`) — native table  
3. **Toggle** (`::part(toggle)`) — Expand/Collapse button with `aria-expanded`  
4. **Cell start** (`::part(cell-start)`) — indent + toggle + first-column value

### Content guidelines

- Caption names the hierarchy (“Project”, “Org”)
- First-column labels should read clearly at every depth
- Leaf rows hide the toggle (control is present but not operable)

### Happy path vs plain

Default ships borders, indent, and focusable toggles. Plain keeps expand/collapse behavior — **you** own chrome and focus paint.

**Folder-style project tree** — seed `expanded-ids` for the path the user cares about; listen for `pond-toggle` to persist open state.

```html
<pond-table-tree
  caption="Project"
  columns='[{"key":"name","label":"Name"}]'
  nodes='[{"id":"src","cells":{"name":"src"},"children":[{"id":"a","cells":{"name":"app.ts"}}]}]'
  expanded-ids='["src"]'
></pond-table-tree>
```

**Prefer Dynamic table** when you need sort + pagination without nesting. **Prefer Table** for a flat static grid. Prefer Side nav for primary app navigation trees.
