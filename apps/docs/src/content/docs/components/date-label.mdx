### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | `''` | ISO date `YYYY-MM-DD` (also sets `<time datetime>`) |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** none.

**CSS parts:** `root` — the native `<time>` element.

**Events:** none.

### Purpose

Show a formatted, non-interactive date. Not for choosing or editing dates.

### Anatomy

1. **Root** (`::part(root)`) — native `<time datetime="…">` with locale-formatted text

### Content guidelines

- Always pass a parseable ISO `value`
- Visible text comes from the locale formatter — do not invent a second conflicting string
- Prefer absolute dates when relative phrasing would confuse (“2 hours ago” belongs in Comment `meta`, not here)

### Happy path vs plain

Default ships sans type size/color. Plain keeps `<time datetime>` — **you** own chrome.
