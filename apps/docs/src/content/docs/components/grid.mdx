Equal-width columns (1–4, 6, or 12) with tokenized gap. Override tracks via `--pond-grid-columns`. Prefer [Stack](/primitives/stack/) for linear reading; [Inline](/primitives/inline/) / [Flex](/components/flex/) for single rows; [Box](/primitives/box/) for surface. `appearance="plain"` strips grid chrome — you own layout CSS.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `'1' \| '2' \| '3' \| '4' \| '6' \| '12'` | `'1'` | Equal-width column count |
| `gap` | space scale (`'0'`–`'12'`) | `'4'` | Gap between cells |
| `align` | `'stretch' \| 'start' \| 'center' \| 'end'` | `'stretch'` | Align items on the block axis |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips grid chrome |

**CSS custom property:** `--pond-grid-columns` — override track definition for custom layouts.

**Slots:** default — grid children (DOM order should stay sensible when columns reflow).

**CSS parts:** `root` — grid container.

**Events:** none (presentational).

### Purpose

Grid is for **equal-column** content matrices — tile pickers, field pairs, card boards. It is **not** a reading stack ([Stack](/primitives/stack/)), toolbar ([Inline](/primitives/inline/)), or free-form flex ([Flex](/components/flex/)).

### Anatomy

1. **Host** — `pond-grid`
2. **Container** (`::part(root)`) — CSS grid
3. **Cells** — default slot

### Content guidelines

- Keep interactive cells large enough for hit targets
- Prefer DOM order that still reads well when the grid wraps
- Use `--pond-grid-columns` for uneven tracks instead of fighting equal columns

### Happy path vs plain

Default ships equal columns, gap, and align. `appearance="plain"` unwraps — **you** own grid CSS.

**Tile picker** — Grid of named nouns.

```html
<pond-grid columns="4" gap="3">
  <pond-tile label="Document">Doc</pond-tile>
  <pond-tile label="Folder">Folder</pond-tile>
  <pond-tile label="Image">Img</pond-tile>
  <pond-tile label="Code">Code</pond-tile>
</pond-grid>
```

**Prefer Stack for linear forms** — a single column of fields is [Stack](/primitives/stack/), not a one-column Grid. Prefer [Inline](/primitives/inline/) for a lone toolbar row.
