Navigates to another page or URL. For in-place actions that stay on the current view, use [Button](/components/button/) — including `variant="link"` when you want text chrome. `appearance="plain"` strips Pond visuals — you own focus paint and contrast.

```html

  >Example.com (opens in a new tab)</pond-link
>
<pond-link href="/docs" appearance="plain">Unstyled link</pond-link>
```

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | `'#'` | Destination URL — always set a real path or URL |
| `target` | `'_self' \| '_blank' \| '_parent' \| '_top' \| null` | `null` | Native target; `_blank` implies safe `rel` unless overridden |
| `rel` | `string \| null` | `null` | Link relationship; defaults to `noopener noreferrer` when `target="_blank"` |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** default — link text (the accessible name).

**CSS parts:** `link` (native `<a>`).

**Events:** standard navigation via the native anchor (no custom Pond events).

### Purpose

Link changes location — another route, document, or external site. It is **not** for submit, toggle, or dialog triggers ([Button](/components/button/)).

### Anatomy

1. **Anchor** (`::part(link)`) — native `<a>`
2. **Label** — default slot (must describe the destination)

### Content guidelines

- Name the destination in the link text (“Fork guide”, not “click here”)
- Sentence case
- If `target="_blank"`, include that fact in the visible text or adjacent copy
- Keep underline for affordance in default appearance

### Happy path vs plain

Default ships accent color, underline, and Pond focus ring. `appearance="plain"` keeps navigation semantics — **you** own focus paint, color, and underline.
