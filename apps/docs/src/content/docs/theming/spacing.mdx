Pond’s space scale is a **4px-based rem ladder** exposed as `--pond-space-*`. Prefer these tokens over raw `px`/`rem` in components and product layouts.

## Scale

| Token | rem | px @16 | Typical use |
| --- | --- | --- | --- |
| `--pond-space-1` | 0.25 | 4 | Icon gutters, tight inline |
| `--pond-space-2` | 0.5 | 8 | Control padding-y, compact gaps |
| `--pond-space-3` | 0.75 | 12 | Field padding, dense stacks |
| `--pond-space-4` | 1 | 16 | Default `pond-stack` gap |
| `--pond-space-5` | 1.25 | 20 | Comfortable control clusters |
| `--pond-space-6` | 1.5 | 24 | Card / demo padding |
| `--pond-space-8` | 2 | 32 | Page section rhythm |
| `--pond-space-10` | 2.5 | 40 | Major section break |
| `--pond-space-12` | 3 | 48 | Hero / page chrome |

`gap="0"` on Stack / Inline collapses to `0` (no token).

## Layout primitives

Use **Stack** and **Inline** so gaps stay on the scale:

```html
<pond-stack gap="4">
  <pond-heading level="2">Section</pond-heading>
  <pond-text>Body copy with default stack gap.</pond-text>
</pond-stack>

<pond-inline gap="3" wrap>
  <pond-button variant="primary">Save</pond-button>
  <pond-button variant="subtle">Cancel</pond-button>
</pond-inline>
```

## Guidance

- **Do** pick the next step on the scale rather than inventing `14px` / `18px`.
- **Do** use smaller steps inside controls; larger steps between sections.
- **Don't** mix raw spacing with tokens in the same component surface.
- **Don't** use space tokens for typography metrics — use `--pond-font-line-*` / size tokens.
