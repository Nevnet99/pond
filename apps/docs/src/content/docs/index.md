Pond is a Lit design system meant to be **forked and owned**. Upstream does not publish to npm.

## What you get

- Brandable `--pond-*` tokens (light + dark)
- Lit primitives and components with `appearance="plain"` reset
- Storybook workbench + Starlight docs
- Vitest unit / axe / VRT wiring and release-please for forks

Start with [Install / fork](/getting-started/fork/) or the [v1 slice](/contributing/v1-slice/).
