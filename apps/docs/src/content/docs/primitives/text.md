Body copy for product UI.

## Examples

Default size uses semantic type tokens. Use `size` and `muted` for variants.

## Code

```html
<pond-text>Body copy for product UI.</pond-text>
<pond-text appearance="plain">Consumer-styled text</pond-text>
```

## Usage

Use for paragraphs and inline product copy. Prefer Heading for page titles.

## Changelog

Unreleased — initial Text primitive.

## Accessibility

Semantic `<p>` inside the shadow tree. In `appearance="plain"`, Pond ships no visual CSS — you own paint and focus.
