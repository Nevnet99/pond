description: Heading primitive (levels 1–6).
---

Page and section titles.

## Examples

Levels 1–6 map to `h1`–`h6`.

## Code

```html
<pond-heading level="1">Page title</pond-heading>
<pond-heading level="2">Section</pond-heading>
```

## Usage

One `level="1"` per view. Do not skip levels for styling — change visual size via tokens later if needed.

## Changelog

Unreleased — initial Heading primitive.

## Accessibility

Renders a real heading element. Plain mode: no Pond visual CSS; you own paint.
