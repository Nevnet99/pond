Padded surface for grouping content. Prefer [Stack](/primitives/stack/) or [Inline](/primitives/inline/) to arrange children — Box only frames. Reach for [Flex](/components/flex/) / [Grid](/components/grid/) when you need reverse, wrap, or columns. `appearance="plain"` strips Pond visuals — you own spacing and paint.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `padding` | `'0' \| '1' \| '2' \| '3' \| '4' \| '6' \| '8'` | `'0'` | Uniform padding from the space scale |
| `background` | `'transparent' \| 'canvas' \| 'surface' \| 'subtle'` | `'transparent'` | Background token |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS (`display: contents`) |

**Slots:** default — box content.

**CSS parts:** `box` — inner layout element.

**Events:** none (presentational).

### Purpose

Box is a surface and padding shell. It is **not** a flex/grid layout and **not** an interactive control — put actions on [Button](/components/button/) or [Link](/components/link/).

### Anatomy

1. **Host** — `pond-box`
2. **Surface** (`::part(box)`) — padded background region
3. **Content** — default slot

### Content guidelines

- Keep copy short inside decorative boxes; long prose belongs in [Text](/primitives/text/)
- One background intent per region
- Do not use Box alone as a click target

### Happy path vs plain

Default applies padding tokens, background tokens, radius, and foreground. `appearance="plain"` unwraps to `display: contents` — **you** own spacing and paint; slot content and semantics stay.

**Section frame** — Box + Stack for a padded block with vertical rhythm.

```html
<pond-box padding="6" background="surface">
  <pond-stack gap="3">
    <pond-heading level="3">Section</pond-heading>
    <pond-text>Supporting copy.</pond-text>
  </pond-stack>
</pond-box>
```

**Prefer Stack / Inline for arrangement** — if you only need gap between children, use [Stack](/primitives/stack/) or [Inline](/primitives/inline/), not nested Boxes.
