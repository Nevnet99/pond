Page and section titles. `level` sets `h1`–`h6`; visual size defaults from level and can be overridden with `size`. Prefer [Text](/primitives/text/) for body copy and [Metric text](/components/metric-text/) for KPIs. `appearance="plain"` strips Pond type CSS — you own font size; keep a real heading element.

```html
<pond-heading level="1">Page title</pond-heading>
<pond-heading level="2">Section</pond-heading>
<pond-heading level="2" size="lg">Same level, smaller type</pond-heading>
<pond-heading level="2" appearance="plain">Unstyled</pond-heading>
```

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `2` | Maps to native `h1`–`h6` |
| `size` | type scale step \| omitted | from `level` | Visual override; omit to use level defaults (h1→5xl … h6→lg) |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** default — heading text.

**CSS parts:** `heading` — native `h1`–`h6`.

**Events:** none (presentational).

### Purpose

Heading owns the **document outline**. It is **not** body copy ([Text](/primitives/text/)) and **not** a KPI numeral ([Metric text](/components/metric-text/)).

### Anatomy

1. **Host** — `pond-heading`
2. **Heading** (`::part(heading)`) — real `h1`–`h6`
3. **Label** — default slot

### Content guidelines

- One `level="1"` per view
- Sentence case unless the product brand requires otherwise
- Never skip levels only to get a visual size — use `size`
- See [Typography](/theming/typography/)

### Happy path vs plain

Default ships display face, weight, tracking, and level→size mapping. `appearance="plain"` unwraps paint — the native heading element remains; **you** own type CSS.
