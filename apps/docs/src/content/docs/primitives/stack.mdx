Vertical column with consistent gap. Default layout for forms and sections. Prefer [Inline](/primitives/inline/) for horizontal toolbars; [Flex](/components/flex/) when you need reverse or space-evenly; [Grid](/components/grid/) for equal columns. `appearance="plain"` strips flex chrome — you own layout CSS.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `gap` | space scale (`'0'`–`'12'`) | `'4'` | Vertical gap between children |
| `align` | `'stretch' \| 'start' \| 'center' \| 'end'` | `'stretch'` | Cross-axis alignment |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips flex chrome |

**Slots:** default — stacked children (DOM order = reading order).

**CSS parts:** `stack` — flex column container.

**Events:** none (presentational).

### Purpose

Stack is the vertical rhythm primitive. It is **not** a table, grid, or horizontal toolbar ([Inline](/primitives/inline/) / [Flex](/components/flex/) / [Grid](/components/grid/)).

### Anatomy

1. **Host** — `pond-stack`
2. **Column** (`::part(stack)`) — flex column + gap
3. **Children** — default slot

### Content guidelines

- Keep DOM order matching reading order (no visual-only reordering)
- Prefer token `gap` over ad-hoc margins between siblings
- Pair with [Box](/primitives/box/) when the column needs a padded surface

### Happy path vs plain

Default ships column flex, gap tokens, and align. `appearance="plain"` unwraps — **you** own flex/gap CSS; children and order stay.

```html
<pond-stack gap="4">
  <pond-text-field label="Email"></pond-text-field>
```

**Prefer Inline for toolbars** — horizontal action rows belong in [Inline](/primitives/inline/), not a sideways Stack.
