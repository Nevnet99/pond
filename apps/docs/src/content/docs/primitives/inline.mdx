Horizontal row with tokenized gap. Toolbars, chip rows, and sibling actions. Prefer [Stack](/primitives/stack/) for vertical order; [Flex](/components/flex/) when you need reverse or space-evenly; [Grid](/components/grid/) for equal columns. `appearance="plain"` strips flex chrome — you own layout CSS.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `gap` | space scale (`'0'`–`'12'`) | `'2'` | Horizontal gap between children |
| `align` | `'start' \| 'center' \| 'end' \| 'baseline'` | `'center'` | Cross-axis alignment |
| `justify` | `'start' \| 'center' \| 'end' \| 'between' \| 'around'` | `'start'` | Main-axis distribution |
| `wrap` | `boolean` | `false` | Allow children to wrap onto new rows |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips flex chrome |

**Slots:** default — row children (DOM order = tab/reading order).

**CSS parts:** `inline` — flex row container.

**Events:** none (presentational).

### Purpose

Inline lays out a **row** of related controls or chips. It is **not** page structure ([Stack](/primitives/stack/) / [Box](/primitives/box/)) and **not** a multi-column matrix ([Grid](/components/grid/)).

### Anatomy

1. **Host** — `pond-inline`
2. **Row** (`::part(inline)`) — flex row + gap
3. **Children** — default slot

### Content guidelines

- Keep interactive children keyboard-reachable in DOM order
- Prefer `wrap` over horizontal scroll for dense toolbars on small screens
- One primary action per row when the row is a decision bar

### Happy path vs plain

Default ships row flex, gap, align, and justify. `appearance="plain"` unwraps — **you** own flex CSS; behavior of slotted controls stays.
