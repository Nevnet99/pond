Body copy for product UI. Sizes map to the type scale (`xs`–`xl`). Prefer [Heading](/primitives/heading/) for outline titles and [Metric text](/components/metric-text/) for short KPIs. `appearance="plain"` strips Pond type CSS — you own font size and color.

### API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Body scale step |
| `muted` | `boolean` | `false` | Muted foreground (ignored when plain) |
| `appearance` | `'default' \| 'plain'` | `'default'` | `plain` strips Pond visual CSS |

**Slots:** default — text content (may include inline [Link](/components/link/)).

**CSS parts:** `text` — semantic `<p>` in the shadow tree.

**Events:** none (presentational).

### Purpose

Text is paragraph body copy. It is **not** a document outline ([Heading](/primitives/heading/)) and **not** a numeric KPI face ([Metric text](/components/metric-text/)).

### Anatomy

1. **Host** — `pond-text`
2. **Paragraph** (`::part(text)`) — native `<p>`
3. **Content** — default slot

### Content guidelines

- Sentence case for product UI
- Cap long-form measure (~60–75ch) on reading columns
- Use `muted` for helpers secondary to a label — not as the only instruction
- See [Typography](/theming/typography/)

### Happy path vs plain

Default ships scale step, weight, line-height, and color. `appearance="plain"` unwraps — **you** own type CSS; keep real paragraph semantics via the slot or your own markup.

**Inline link in prose** — wrap Link inside Text so size/line-height inherit.

```html
<pond-text>
  See the <pond-link href="/getting-started/fork/">fork guide</pond-link>.
</pond-text>
```

**Prefer Heading for titles** — if the string belongs in the page outline, use [Heading](/primitives/heading/), not a large Text size.
